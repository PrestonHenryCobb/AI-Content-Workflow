# Channel description (≤1000 chars; first ~150 chars show in search)

```
Unsolved cold cases, strange disappearances and real true crime mysteries, told as case files recovered from an unmarked disc.

A new case every 8 hours. Every Sunday, the full archive: the week's cases expanded into one long file.

Every case here is real and researched from public records, official case databases and published reporting. Sources are listed in each video's description. We don't name people who were never charged, and we don't show real victims' faces.

If you have information about a case, contact the agency listed in the video or the NamUs database (namus.nij.ojp.gov). If you're connected to a case and want a video changed or removed, use the email on the About page and it will be handled immediately.

Visuals, narration and production are AI-assisted. The cases are not.

Cold Save — case archive.
```
