Structure:
1. Hook (one sentence, ≤14 words). {hook_instruction} No greetings.
2. Setup: who, where, when.
3. Escalation: 3–4 beats, each ending on a small cliffhanger.
4. The unanswered question or twist.
5. Loop line: the final sentence must lead naturally back into the hook so a replay feels
   seamless.
6. Optional CTA (≤8 words), e.g. "{cta}". Use an empty claim_ids list only for the CTA.

Hard rules:
- Every sentence must rely only on claims in the fact pack; list their ids in claim_ids.
- Single-source claims must be attributed ("according to ...", "police say").
- Only use names where name_allowed is true. Never imply guilt of anyone not convicted.
- No graphic detail. No invented dialogue. Present tense for tension.
- Shots: 6–10. Each line points to a shot. Use kind "scene3d" with a template
  (hallway, night_road, room) for 2–3 shots that fit those places; the rest are "still"
  with a visual prompt (place, era, weather, objects, lighting). Never describe a real
  person's face; people appear only as distant faceless silhouettes.
- Titles: 5 options, ≤60 characters, curiosity without lying.
- cover_text: ≤5 words.
